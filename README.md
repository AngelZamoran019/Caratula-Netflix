# Carátula Netflix

Carátula personalizada estilo Netflix, construida con React + Vite.

## Configuración

Toda la personalización inicial está en:

`src/config.js`

Puedes configurar:

- Foto principal
- 5 fotos inferiores
- Foto de avatar
- Título

Las imágenes se pueden proporcionar mediante URLs públicas HTTPS.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Crear versión de producción

```bash
npm run build
npm run preview
```
